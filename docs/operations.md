# Эксплуатация

## Vercel и Neon

1. Разверните репозиторий как Next.js проект Vercel с Node.js 24. В Production задайте `DATABASE_URL`, `SESSION_SECRET` и `TELEGRAM_BOT_TOKEN` как чувствительные переменные, а также `APP_URL` и `TELEGRAM_BOT_USERNAME`.
2. Примените миграции к нужной ветке Neon. `npm run bundle:neon` собирает ZIP с `index.mjs`. Разверните его как функцию `polytrader` с runtime `nodejs24`. Neon инжектирует `DATABASE_URL`. Добавьте переменные функции `TELEGRAM_BOT_TOKEN`, `TELEGRAM_WEBHOOK_SECRET` и `APP_URL`.
3. Добавьте два Schedule Trigger для функции `polytrader`. `polytrader-monitor` вызывает `/monitor` раз в минуту (`* * * * *` UTC), `polytrader-daily` вызывает `/daily` в 07:00 UTC (`0 7 * * *`). Минутная задача проверяет историю, BTC-каталог, ожидающие расчёты и активные кошельки. Комбо опрашиваются раз в пять минут. Дневная задача обновляет кандидатов и отправляет отчёт.
4. Выполните `npm run telegram:configure -- <https-url-Neon-Function>`. Команда привязывает webhook, кнопку меню и список команд. После замены токена обновите обе среды и повторите настройку.

Проверьте проводки командой `npm run db:verify`. Тестовая транзакция откатывается. Проверьте `/api/health` на Vercel, `/health` на Neon и «Источники данных» в приложении. Для входа в браузере откройте полученную ссылку и нажмите Start в Telegram. В личном чате доступны `/start`, `/stats`, `/pause` и `/help`.

## WebSocket-сборщик

Запустите `npm run collector` на постоянно работающем Node.js 24 с синхронизированными часами, `DATABASE_URL` и, если нужны быстрые уведомления, токеном бота. Используйте один экземпляр для проекта. Источник данных — публичный рыночный WebSocket CLOB. Сборщик заново подписывается после разрыва, отбрасывает предыдущий стакан и пишет heartbeat каждые 10 секунд. Храните секреты в окружении процесса. Остановка сборщика отображается в интерфейсе и не блокирует расписание Neon.

## Ресурсы

При опросе раз в минуту PostgreSQL на Neon Free может оставаться активным непрерывно. Минимальные 0,25 CU дают около 400 активных часов на 100 CU-часов месячной квоты. Для непрерывного 21-дневного запуска проверьте доступные CU-часы и дату обновления квоты. Периодические проверки и WebSocket-сборщик используют одну базу. [Условия Neon Free](https://neon.com/blog/neon-free-plan-1-gb-per-project).

Архив кошельков останавливает историческую догрузку при достижении 750 MiB. Приложение сохраняет позицию курсора и отображает неполное покрытие. Живые наблюдения сохраняются отдельно от прогресса исторической выгрузки.

## Проверка и восстановление

- Таблицы `lab.job_runs`, `lab.heartbeats` и `lab.logs` содержат информацию о периодических заданиях. Ошибки агрегируются в настройках.
- Сигналы, решения, Telegram updates и очередь исходящих уведомлений защищены ключами от повторной записи. Telegram Bot API не предоставляет идемпотентного ключа для отправки сообщений, поэтому при обрыве между отправкой и записью результата сообщение может продублироваться.
- Частичные исполнения сохраняют фактическую виртуальную сумму. Закрытие использует официальный статус расчёта Gamma. Позиции с неподтверждённым исходом остаются открытыми.
- Новая методология стратегии требует новой версии и нового теста. Схема не переписывает результаты предыдущих версий.
