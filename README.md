# PolyTrader Lab

Telegram Mini App и веб-лаборатория для перспективного Paper Trading на Polymarket. Банк, позиции и сделки виртуальные. Стаканы, активность кошельков, котировки и результаты рынков поступают из публичных API.

## Запуск

1. Установите Node.js 24 и выполните `npm ci`.
2. Скопируйте `.env.example` в `.env.local`. Укажите Neon `DATABASE_URL`, токен и имя бота, случайные `SESSION_SECRET` и `TELEGRAM_WEBHOOK_SECRET`, публичный `APP_URL`.
3. Выполните `npm run db:migrate`, затем `npm run dev`. В браузере вход подтверждается в личном чате с ботом. В Mini App сервер проверяет подписанный Telegram `initData`.
4. Для проверки проекта выполните `npm test`, `npm run typecheck` и `npm run build`.

Публикация веб-приложения, Neon Function, расписания и сборщика описана в [инструкции по эксплуатации](docs/operations.md). Модели, статистика и исторические гипотезы описаны в [методологии](docs/research.md).

## Рабочий цикл

Откройте «Стратегии», задайте банк, ставку с комиссией, лимит открытых позиций, предельную просадку и допустимое проскальзывание. Выберите 7, 14, 21 день или задайте период. «Оба режима» создаёт независимые банки с одинаковыми зафиксированными правилами. Для подтверждений и уведомлений отправьте боту `/start`.

«Журнал» показывает пропущенные, отклонённые, частичные и исполненные сигналы. «Портфель» показывает свободный капитал и подтверждённые оценки. «Аналитика» сравнивает рассчитанные результаты и показывает точность BTC-окон.

## Компоненты

- Next.js, Tailwind CSS, компоненты в стиле shadcn/ui и Recharts на Vercel.
- Neon PostgreSQL хранит рыночные данные, версии, сигналы, решения, позиции, оценки и ошибки. Денежные проводки и расчёт атомарны.
- Neon Function выполняет мониторинг и принимает Telegram webhook. Расписание Neon управляет периодическими задачами.
- Опциональный Node.js WebSocket-сборщик отвечает за точные окна BTC и модель Market Making. Его состояние видно в интерфейсе.
